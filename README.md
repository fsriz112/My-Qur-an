# Nur — Baca Al-Qur’an

Situs pembaca Al-Qur’an dengan daftar 114 surah, pencarian, pilihan surah, teks Arab, transliterasi latin, dan terjemahan bahasa Indonesia.

## Menjalankan

Buka `index.html` melalui server web lokal, misalnya Live Server di VS Code. Data surah dan ayat dimuat dari [equran.id](https://equran.id/), jadi koneksi internet diperlukan.
